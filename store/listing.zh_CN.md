# Chrome Web Store listing: Simplified Chinese

Paste the description below into the developer dashboard under the Simplified Chinese (zh_CN) listing. The title and summary come from the manifest (`manifest.name` and `manifest.description` in `src/locales/zh_CN.json`), so there is nothing to enter for them. Everything else (category, images, URLs, privacy) is in `listing.md`. Name at most three sites as a list of examples, and others only inside an example of what a shortcut does there (`listing.md` says why).

```text
适用于任意网站的键盘快捷键和无鼠标导航：用 j 和 k 滚动页面，用链接提示点击任意链接或按钮，切换标签页，还可以为页面上的任何内容设置自己的快捷键，比如食谱网站的“保存”按钮或视频下方的“点赞”按钮。GitHub、Gmail 和 YouTube 等网站的预设会补充它们缺少的按键，遇到网站已使用的按键则自动让行。你自己的快捷键始终优先。

• 所有网站通用的按键：j 和 k 滚动，d 和 u 移动半页，g g 和 G 跳到顶部和底部，H 和 L 后退和前进，J 和 K 切换标签页。
• 链接提示：按 F，视野内的每个链接和按钮都会显示一个简短标记，输入标记即可点击。按 g f 则在新标签页中打开链接。
• 为任何内容设置按键：点击工具栏上的 AnyKey 按钮，选择“为此网站添加快捷键”，选中元素，然后按下你想要的按键。AnyKey 会用多种方式记住每个元素，即使网站改版，快捷键仍能找到它。
• 网站预设：在 GitHub 上用 g r 打开仓库的发布页，在 YouTube 上用 g l 给视频点赞，在 Stack Overflow 上用 g j 跳到被采纳的回答。如果网站有自己的按键，比如 YouTube 视频上的 j 和 k，按键会交给网站。
• 在任意页面按 ? 查看当前可用的所有快捷键，有预设的网站会先列出网站自带的快捷键。
• 可以更改任意按键、关闭任意快捷键，或在某个网站上关闭 AnyKey。当两个快捷键冲突或浏览器保留某个按键时，会显示警告。设置会随浏览器同步，也可以导出到文件。
• Alt+Shift+K（Mac 上为 Option+Shift+K）可在任意标签页打开 AnyKey 面板。
• 支持简体中文、英语、西班牙语、德语和印地语。

AnyKey 不收集任何数据，也不发送任何网络请求。你的快捷键只保存在你的浏览器中。
```
